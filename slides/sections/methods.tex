\begin{frame}{Three reductions that make the tasks tractable}
  \begin{itemize}
    \item \textbf{T3:} multi-source Dijkstra $=$ Dijkstra from a virtual super-source; first source to settle a node owns it. One run instead of $|S|$
    \item \textbf{T5:} each pipe $\to$ two arcs of capacity $c$; max flow $=$ capacity of the min cut, whose saturated pipes are the bottleneck
    \item \textbf{T6:} optimal walk $=$ optimal tour on the metric closure $D_{uv}=d_G(u,v)$, expanded back into real pipes. Branch and bound prunes with
    \[\mathrm{LB}=\mathrm{cost}+\mathrm{MST}(R)+\min_{r\in R}D_{ur}+\min_{r\in R}D_{ro}\]
  \end{itemize}
  \note{The T6 reduction matters because the networks have no Hamiltonian cycle: the technician must revisit nodes. Reading any walk as its order of first visits gives a tour that is no longer, and each tour expands into a walk of the same length.}
\end{frame}
